# Cliente 03 — Metropole Pet Shop e Clinica Veterinaria

Landing page: https://cliente-03-metropole.vercel.app

## Estrutura
- `index.part1..5.html` — HTML em 5 partes (concatenadas no build)
- `assets/styles.part1..2.css` — CSS em 2 partes
- `assets/app.js` — agendador WhatsApp, carrossel, FAQ, menu mobile
- `og-p01..02.b64`, `favicon-p01.b64` — imagens em chunks base64
- `scripts/build.js` — roda na Vercel

## Deploy
Push na `main` -> build Vercel -> producao.
